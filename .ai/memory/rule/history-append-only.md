# history.md 는 append-only

각 작업 폴더의 `history.md`(`.ai/projects/{작업명}/history.md`)는
**"어떻게 지금까지 왔는지" 를 남기는 누적 기록**이다. 따라서 append-only 로만 다룬다.

## 규칙

- **과거 항목 수정 금지.** 이미 적힌 줄은 고치거나 지우지 않는다.
- 새 진행은 **맨 아래에 새 줄(항목)로만 추가**한다.
- 날짜별로 간략히 요약해 쌓는다. (새 세션에서 맥락을 이어가기 위함)
- 나중에 결정이 번복되더라도, 과거 항목을 고치지 않고 **"번복했다" 는 사실을 새 항목으로 추가**한다.
  (그래야 결정이 바뀌어 온 경위 자체가 기록으로 남는다.)

## 왜

- `history.md` 의 가치는 "현재 상태" 가 아니라 **"거기까지 온 과정"** 에 있다.
- 과거 항목을 고치면 그 과정이 사라져, 새 세션에서 왜 이렇게 됐는지 추적할 수 없다.
- "현재 확정 상태" 는 `spec.md` 가, "열린 항목" 은 `request.md` 가 담당한다. ([[../../index.md]] 참고)

## 원칙

- history 는 **쌓기만** 한다. 수정·삭제가 필요하다고 느끼면, 그건 대부분 spec/request 에 반영할 일이다.
